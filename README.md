Drag_prediction_public
Python code for the publication "UAV Icing: Drag Increase Prediction Based on Batch-Automated CFD Simulations" by Joachim Wallisch, Markus Lindner, Richard Hann, and Kasper T. Borup

This repository consists of 4 Python scripts:

- "Correlation_fitting_v2" was used to find the best parameters for many different equation baselines.
- "New_correlations" was used to analyze and plot the prediction results, also for the extended parameter range.
- "Existing_correlations" was used to analyze the prediction of the existing drag equations.
- "real_life_applications" was used to plot and analyze the prediction of the new expressions for certain real-life scenarios.
